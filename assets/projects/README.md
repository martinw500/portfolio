## Capturing

Capture at the size you intend to publish. **Do not shoot at 2× and downscale** —
for pixel art that blurs the edges and roughly quadruples the PNG by inventing
intermediate colours. The game set went from 1.28MB to 404KB by fixing this.

Missing files degrade to nothing, so a project with no screenshots simply renders
without a figure block rather than showing a placeholder.
